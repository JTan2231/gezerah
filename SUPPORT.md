# Support

Use the repository's issue tracker for reproducible bugs, documentation
problems, and focused feature proposals. Search existing issues first.

Include:

- the commit or version tested;
- operating system and relevant Go, Bun, PostgreSQL, and browser versions;
- exact reproduction steps and expected versus observed behavior;
- the smallest useful log excerpt or screenshot.

Remove passwords, cookies, CSRF tokens, database URLs, API keys, invitation
links, private notes, and other sensitive data before posting. For a suspected
vulnerability, do not open an issue; follow [SECURITY.md](SECURITY.md). For a
conduct concern, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Wrought is under active development and has no guaranteed support or response
time. The hosted instance is a conditional preview, not a public-production
service. Accounts intentionally have no email address or password-recovery
flow, so maintainers cannot recover a forgotten password through support.

For development and operational questions, start with the
[system documentation](docs/README.md), especially the
[development guide](docs/development.md), [testing guide](docs/testing.md), and
[operations runbook](docs/operations.md).
